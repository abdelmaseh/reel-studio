# Showcase credits

The README gallery features Mohamed Abdou's work made with the full editing system from which Reel Studio was built. Each scene was designed for its video's content. Silent previews are presentation assets; the distributed kit's reusable components are described in [the technique guide](../../instructions/TECHNIQUES.md).

## Examples

- Before-and-after clips, collage, Arabic typography and data graphics show different editing directions.
- API vs MCP and Claude Code Mods use individually designed diagrams and illustrative interfaces.
- Reel Factory and Gold Flight are custom three-dimensional ads. Their generated narration was prepared outside the distributed kit.
- The Abu Dhabi event reel combines the presenter, graphics and supporting event imagery.
- The podcast example comes from a batch of 30 short videos, including 10 with explanatory motion scenes.
- The ChatGPT and Canva tutorial combines the presenter, screen steps and visual callouts.
- The clinic workflow uses paper cards and connections to explain a customer journey.
- The style gallery shows eleven rendered stills, one for each style, with illustrative content; none of them is a playback link. The Section Deck, Kinetic Paper, Magazine Interview, Liquid Glass, Calligraphic Receipts and Paper Collage stills (redesigned in 4.0) are frames of the studio's own library preview with neutral sample copy, rendered with the studio itself; the numbers on them are labelled as illustrative and are not measurements. The Grid Glide and One Shot stills are frames from synthetic demonstrations (generic copy and generated screens) rendered with the studio itself. The Cartoon still (`docs/images/style-cartoon.jpg`) is a frame of a demonstration edit with neutral copy and the generic default character, rendered with the studio itself; the character is original art, not anyone's likeness. The Documentary still (`docs/images/style-documentary.jpg`) is a frame of the studio's own library preview: an illustrative route between authored coordinates on the installed map, with no real journey claimed. The Layered Speaker still (`docs/images/style-layered-speaker.jpg`) is a frame of the library preview, where an abstract drawn shape stands in for the speaker; no person appears.
